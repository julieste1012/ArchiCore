Estado del Aggregate

Requiere enriquecimiento
antes de implementación.

Razones:

- No define atributos.

- No define métodos.

- No define Factory.

- No define colecciones.

- No define referencias.

- No define eventos coherentes
con DomainEvents.

información para una implementación
DDD consistente.
