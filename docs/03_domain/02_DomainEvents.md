# Purpose

This document defines relevant business events generated by the ERP. A domain event represents something important that has happened in the business. Events are immutable and every persisted event is projected to the audit stream.

# Event Naming Convention

Every event is written in the past tense, for example CustomerCreated, ContractActivated and FolderStored.

# Audit Principle

Every persisted domain event must generate an audit entry. Sensitive file bytes, passwords, tokens and secret material must never be included in event payloads.
