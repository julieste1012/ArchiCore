# Purpose

This document defines every relevant business event generated by the ERP.

A domain event represents something important that has happened in the business.

Events are immutable.

---

# Event Naming Convention

Every event is written in the past tense.

Examples

CustomerCreated

ContractActivated

ReceptionCompleted

LoanAuthorized

FolderStored
